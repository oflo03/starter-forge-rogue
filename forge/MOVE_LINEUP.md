# 창작 기술 전체 목록

현재 게임 보상에 등장하는 **222종**, 등급·레벨별 실제 등록 변형 **1944개**입니다. 기술 보상은11·31·51레벨이며21레벨은 특성,41레벨은 패시브입니다. 원작 범용 기술과 과거 저장 호환용21·41레벨 변형은 이 목록에서 제외합니다.

위력의 세 숫자는 **11 / 31 / 51레벨** 순서이며 —는 해당 레벨에 나오지 않음을 뜻합니다. 연타 위력은1타 기준입니다. PP와 부가확률의 세 숫자는 **실버 / 골드 / 프리즘** 순서입니다. 아래 설명은 골드 기준이며 등급에 따라 달라지는 부가확률도 별도로 표시합니다. 확정 급소는 단타·위력70 이하, 해당 공격 종족값110 이하 조건을 유지합니다.
