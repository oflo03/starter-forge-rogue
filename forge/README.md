## 시작과 파트너

타이틀에서 **모험 시작**을 선택합니다. 이 배포판은 60웨이브 모드만 제공하며, 로그인·튜토리얼·스타팅 선택·도감/사탕/알 뽑기·다른 모드 메뉴는 표시하지 않습니다. 심리테스트나 시드 입력은 없습니다. 매 모험마다 암호학적 난수로 맵 시드와 파트너 시드를 새로 만듭니다. 시드는 **메뉴 → 설정 → 일반**의 하단 메시지에서만 확인할 수 있습니다.

처음에는 서로 다른 단일 타입 세 개를 증강 형태의 카드로 제시합니다. 선택 전에는 원작 타입 아이콘만 표시하고 파트너의 모습은 숨깁니다. 한 타입을 고르면 Lv.5 파트너의 앞모습을 보며 이름을 직접 짓습니다. 후보는 매 모험의 무작위 시드로 정해지고 선택 후 체형과 타입이 그대로 이어집니다. 10웨이브 클리어 뒤에는 Lv.10 두 번째 파트너를 만나 타입 세 개 중 하나를 고른 뒤 모습을 보고 이름을 정합니다. 20웨이브에는 추가 합류가 없으며, 창작 성장 파트너는 총 두 마리입니다. 포획·돈·도구·상점·교대·기술머신·경험치 획득·원작 포켓몬의 기술과 특성은 원본 시스템을 사용합니다. 원작 포획 편성은 유지하며, 편성이 가득 찬 상태에서 성장 파트너가 합류하면 작별할 일반 포켓몬을 직접 고릅니다.

파트너는 6개 체형 × 3단계 진화 × 앞뒤 모습, 총 36개 96×96 도트 프레임을 사용합니다. 날렵형(카코미슬)·표준형(줄무늬텐렉)·튼튼형(빈투롱)·묵직형(타킨)·갑옷형(아르마딜로)·풍선형(덤보문어)을 최종 종족값의 27개 형태에서 분류합니다. 체형은 진화와 저장 복원 후에도 유지됩니다. 타입마다 몸색·무늬색 두 색을 지정해 단일 타입도 무늬가 보입니다. 복합 타입은 두 타입의 대표색을 몸색과 무늬색에 사용합니다. 전투에서는 뒷모습의 발밑을 원본 플랫폼에 맞추고, 정보창·파티·이름 입력창은 앞모습을 중앙에 표시합니다. 진화 단계 숫자는 표시하지 않습니다. 1·2·3단계는 최대 치수 64·76·86픽셀로 커지며, 모든 프레임의 실제 윤곽을 96×96 캔버스 중앙에 배치합니다. 시트의 칸 경계 대신 연결된 전체 윤곽으로 추출해 귀·꼬리·발이 잘리지 않게 합니다. 이름 입력창도 고정 잘라내기 없이 전체 그림을 표시합니다. 상대 및 포획한 원작 포켓몬 이미지는 그대로 유지합니다. [전체 프레임과 팔레트 미리보기](art/normal-base/index.html)에서 확인할 수 있습니다.

초기 기술 세 개는 모두 원작 기술입니다. 시작 특성은 첫 타입 기술을 HP 1/3 이하에서 강화하는 심록 계열입니다. 풀·불꽃·물·벌레는 원작 심록·맹화·급류·벌레의알림을 그대로 사용하고, 나머지 타입은 같은 원본 효과 속성을 쓰는 확장 특성을 사용합니다. 지정 성장 보상 외의 경로로 창작 기술·특성을 자동 배정하지 않습니다.

## 성장

최종 종족값은 기존 메이커의 시드 생성식으로 결정하며 총합은 530입니다. 진화 단계별 기본 종족값 총합은 정확히 **310 → 420 → 530**입니다. 최종 값이 40 이하인 능력치는 모든 단계에서 그대로 유지합니다. 나머지는 비례 조정하되 HP·공격·방어·특공·특방·스피드 하한 **40·50·40·30·10·10**을 지키고, 정수화 후 차이는 조정 가능한 능력치에 배분합니다. 도구·융합·전투 중 보정은 원본 규칙으로 별도 적용합니다.

| 레벨 | 성장 선택 |
| --- | --- |
| 11·31·51 | 창작 기술 하나. 한방·유틸·템포 후보를 함께 제시 |
| 16 | 원작 1차 진화 연출 |
| 21 | 공통 풀에서 특성 선택 |
| 36 | 현재 타입을 제외한 랜덤 타입 3개 중 선택 → 최종 진화 연출. 특성 보상 없음 |
| 41 | 같은 풀에서 특성 하나를 패시브 슬롯에 추가 |
| 46 | 모든 개체값 +5 또는 하나를 V(31)로 조정 |

56레벨에는 별도 보상이 없습니다. 특성과 패시브는 같은 풀을 사용하며 21·41레벨에 하나씩 받습니다. 원작249종과 창작 환경 생성9종·활용9종, 실제 후보267종으로 실버118·골드113·프리즘36종입니다. 일루전은 골드 분류를 기록하되 미구현으로 추첨에서 제외합니다. 자력·솜털은 실버입니다. 이미 장착한 특성은 제외합니다. 힘자랑·브레인파워·겹겹코트·밸런스기어는 새 후보에서 제외합니다. 기존 저장에서 이미 얻은 효과는 보존하고, 과거 16·26레벨 특성·패시브는 중복 지급하지 않습니다. 기존 21·41레벨 기술 보상 이력과 새 특성 보상 여부를 따로 저장합니다. 개체값 이벤트는 46레벨이며 과거56레벨 지급 이력도 보존합니다.

기술·특성 증강마다 실버 50%·골드 35%·프리즘 15%로 등급을 결정하며 세 카드는 같은 등급입니다. 카드마다 무료 새로고침 2회가 있고, 해당 카드만 바뀌며 등급은 유지됩니다. 파티 확인 후에도 남은 횟수는 유지됩니다. 가능한 한 이미 본 후보를 제외하고 후보가 부족하면 이전 후보가 다시 나올 수 있지만 현재 세 카드는 중복되지 않습니다. 36레벨 타입 선택과 46레벨 개체값 이벤트에는 등급별 강화나 새로고침이 없습니다. 키보드는 위·아래로 카드와 새로고침 버튼 사이를 이동합니다.

성장 보상은 증강 카드 세 장을 나란히 표시하며, 기술·특성 효과와 수치를 카드 이름 바로 아래에 함께 표시합니다. 마우스·터치·키보드 선택과 파티 확인을 지원합니다. 추가 타입은 현재 타입을 제외하고 무작위로 뽑은 세 타입을 원작 타입 아이콘 카드로 바로 제시합니다. 하나를 고른 뒤 최종 진화합니다. 특성 선택은 기술을 자동 습득시키지 않습니다. 기술이 네 개면 교체할 기술이나 ‘배우지 않기’를 직접 선택합니다. 선택창은 열리고 1.2초 동안 입력을 막으며, 열릴 때 누르고 있던 키·터치를 놓아야 합니다. 확인 입력을 연타 중이면 0.35초 이상 멈춘 뒤 새 입력으로 선택합니다. 게임 배속과 관계없이 적용하며, 파티 확인에서 돌아와도 다시 대기합니다.

카드는 아래에서 0.1초 간격으로 나타나 살짝 튕기며 정렬되고 상단이 짧게 빛납니다. 선택 시 나머지 카드는 어두워지고 선택한 카드가 올라오며 약 0.21초 뒤 확정됩니다. 확정 중 추가 입력은 무시합니다. 운영체제의 동작 줄이기 설정에서는 등장·확정 모션을 생략하며 입력 대기시간은 유지합니다.

맵 시드는 성장 보상의 등급을 바꾸며, 파트너 시드·레벨·등급으로 후보를 고릅니다. 원본 경험치 배분과 도구 효과에 전투 경험치 2배를 적용합니다. 레벨 상한은 10웨이브마다 15 → 25 → 35 → 45 → 55 → 60으로 올라갑니다. 플레이와 교대·도구 선택에 따라 보상을 받는 실제 웨이브는 달라집니다.

| 웨이브 | 고정 전투 |
| --- | --- |
| 5 | 첫 라이벌 · 2마리 · Lv.7~8 |
| 25 | 라이벌 · 3마리 · Lv.25~28 |
| 40 | 악의 조직 보스 · 4마리 · Lv.37~40 |
| 55 | 라이벌 · 4마리 · Lv.52~55 |
| 60 | 최종 보스 · 원본 챔피언 6마리 · Lv.56~60 |

일반 야생 포켓몬은 대략 Lv.4 → Lv.57로 점진적으로 강해집니다. 40웨이브 악의 보스는 원본 115웨이브 편성에서 선두 세 마리와 에이스를 남기며 전설·환상·준전설은 원본 일반 멤버로 대체합니다. 트레이너 포켓몬의 다중 HP 구간은 없으며 개체값 상한은 진행에 따라 28까지 증가합니다. 적 소지 도구는 25웨이브 전 0개, 25~54웨이브 1개, 55웨이브 이후 2개로 제한하고 같은 도구 중첩은 1개로 제한합니다. 기존 저장의 진행 중 전투는 저장된 상대 편성을 유지하며, 새로 생성되는 전투부터 적용됩니다.

특성 등급은 사용자가 지정한 목록으로 교체했습니다. 명시한 개별 등급을 우선하고, 나머지 날씨·필드 생성 특성은 골드로 배치합니다. 멀티스케일·스펙터가드·화학변화가스·변환자재·고대활성·쿼크차지·편승 등은 프리즘, 재생력·가속·부자유친·소울하트·심술꾸러기·단순 등은 골드입니다. 발광의 명중·회피 효과를 포함해 원본 전투 구현은 유지합니다. 전체 목록과 추첨 제외 항목은 CONTENT_LINEUP.md에 기록합니다.

기술 보상은 11·31·51레벨에 제공하지만 레벨별 변형은 없습니다. 일반 기술은 기존11레벨, 날씨·필드 생성기9종은 피해 없는 변화기이며 모든 보상 레벨에서 같은 후보를 사용합니다. 등급별 차이와 확정 급소 제한은 유지합니다. 기존 저장의 과거 ID는 보존하되 새 추첨에서 제외합니다. 과거 날씨·필드 생성 공격은 변화기로 전환합니다. 타입별 변형은 통합하지 않습니다. 형태별 검토 목록은 [MOVE_ARCHETYPES.md](MOVE_ARCHETYPES.md)에 정리했습니다.

별도로 실버 기술은 골드 기준 위력의 0.85배, 프리즘은 1.2배를 5 단위로 반올림합니다. 최대 위력은 240, 확정 급소기는 70이며 프리즘은 PP가 5 늘어납니다. 확률 부가효과(1~99%)는 실버 0.75배·프리즘 1.25배로 정수 반올림하고 1~100%로 제한합니다. 확정 효과는 그대로 유지합니다.

## 창작 날씨와 필드

모든 창작 환경의 기본 지속 시간은 5턴입니다. 원본 날씨·필드 슬롯과 지속 시간·저장·해제·UI를 사용하며, 각각 동시에 하나씩 존재할 수 있습니다. 21·41레벨 특성 증강과 31레벨 이후 공격 기술로 생성합니다. 날씨 생성 특성는 어둠내림·바람몰이·고요한숨·매캐한숨·먹구름부름이며, 필드 생성은 모두 메이커 이름을 사용합니다. 원작 날씨·필드는 그대로 존재합니다. 새로운 설치물은 추가하지 않습니다.

| 날씨 | 효과 |
| --- | --- |
| 어두운 오라 | 악 피해 1.2배, 페어리 피해 절반. 솔라빔 위력 절반, 아침햇살·달빛·광합성 회복량 최대 HP의 1/4. 웨더볼 악 |
| 강풍 | 매 턴 시드 난수로 한 진영만 우선도 +3. 웨더볼 비행 |
| 조용한 안개 | 명중률 0.7배, 기술·특성·도구의 풀죽음 확률 2배(최대 100%). 솔라빔·회복기 페널티는 어두운 오라와 동일. 웨더볼 고스트 |
| 독가스 | 독 타입 매 턴 HP 1/16 회복. 독·강철 외 매 턴 HP 1/16 피해. 소리 기술·기충전·용의숨결 실패 시 사용자 HP 1/8 피해. 바람 기술로 해제. 웨더볼 독 |

날씨 효과는 원작 에어록·날씨부정으로 억제됩니다. 독가스의 날씨 피해는 원작 날씨 피해 방지 효과를 따르고, 독가스 폭발·낙뢰는 비접촉 간접 피해로 처리합니다. 낙뢰는 땅에 무효이며 물·비행 등 타입 상성을 곱합니다.

| 옥타곤 | 격투 피해 1.2배. 살아 있는 포켓몬 교체·강제 교체 불가. 회피 보정을 무시하고 명중 보정은 적용. 대지의파동 격투 |
| 화이트 페인트 | 모든 포켓몬과 기술이 노말 타입. 스킨과 타입 변경 효과 무효. 웨더볼·대지의파동 위력 증가는 유지하고 타입만 노말 |
| 스왐프 | 접지한 물·땅 외 스피드 절반. 접지한 모든 포켓몬에게 5카운트: 매 턴 -1, 비·뇌우에는 -2(최소 0), 0이면 기절. 물·땅은 속도 감소만 면역. 비접지·교체·필드 해제로 카운트 초기화. 대지의파동 땅 |

개미굴·옥타곤·화이트 페인트의 명시된 전체 효과는 비접지 포켓몬에도 적용합니다. 스왐프의 속도·카운트는 접지 여부를 따릅니다. 필드가 사라지면 타입·회피·속도 보정은 원상 복구됩니다.

## 전투 구현과 저장

실제 진입점은 원본 `index.html` → `src/main.ts` → Phaser `BattleScene`입니다. 원본 PhaseManager·MoveEffectPhase·타입·급소·명중·상태이상·날씨·필드·도구·상점·AI를 사용합니다. 창작 데이터도 원본 `allMoves`·`allAbilities`에 등록하고 원본 효과 속성으로 처리합니다. 예전 별도 전투 엔진 `forge/game.ts`는 개발 기록으로 남았으며, 배포 게임에서는 실행하지 않습니다.

현재 창작 보상은 구현·검증한 공격기·흡수·반동·선공·필중·급소·방어/특방 하락·풀죽음·2연타·환경 생성 공격과 원작 특성·창작 날씨 및 필드 생성 특성을 노출합니다. 위 표의 창작 날씨 5종과 필드 4종은 실제 전투에 구현되어 있습니다. 기존 메이커의 모든 복합 전용기와 모든 특성을 포팅한 것은 아니며, 지원하지 않는 효과는 보상에 나오지 않습니다. 원작 포켓몬·기술·특성은 원본 구현 범위를 그대로 사용합니다.

로그인 없이 원본의 로컬 저장 슬롯을 사용합니다. `CustomPokemonData.forge`에 시드·단계별 종족값·완료 보상을 보존합니다. 저장 복원 시 아직 선택하지 않은 성장 보상을 다시 확인합니다. 이전 간소화 엔진의 JSON 기록은 원본 슬롯 형식과 달라서 가져오지 않습니다.

## 개발·검증·배포

Node.js 24.9 이상과 pnpm이 필요합니다.

```sh
git submodule update --init --depth 1 assets locales
pnpm install --ignore-scripts
pnpm forge:dev
pnpm forge:typecheck
pnpm forge:test
pnpm forge:test:stats
pnpm forge:build
```

개발 주소는 http://127.0.0.1:5190 입니다. 빌드 결과는 루트 `dist/`이며, 원본 자산과 번역도 함께 복사합니다. Firebase의 `starter-forge-rogue-oflo` 사이트만 사용하므로 기존 스타팅 메이커 사이트는 변경하지 않습니다.

```sh
git archive --format=zip --output=dist/source.zip HEAD
firebase deploy --only hosting --project starter-forge-oflo
```

원본과 변경 소스는 루트 `LICENSE`의 AGPL-3.0을 따릅니다. 원본 이미지·음악·글꼴의 표기와 라이선스는 assets·locales 서브모듈을 참고하세요. 사용하지 않는 예전 모드의 별도 글꼴과 스프라이트 자료는 해당 폴더의 출처 표기를 유지합니다.

## 창작 환경 활용 특성

악한 마음·바람읽기·헛발받기는 프리즘, 맹독압축·흙벽·벼락저금·코너워크·밑그림·진흙시계는 골드입니다. 모두 실제 전투에 구현되며 기존 특성·패시브 슬롯에 배정합니다. 수치와 발동 조건은 CONTENT_LINEUP.md를 따릅니다. 강풍의 진영 선택은 동일 턴의 AI·실행에서 일치하는 시드 해시를 사용하며, 낮은 비트가 턴마다 단순히 교대하던 현상을 혼합 단계로 수정했습니다.

## 원본 기술 습득·진화 UI

증강 카드에서 기술을 고른 뒤 원본 LearnMovePhase로 습득·교체·포기를 처리합니다. 네 기술을 알고 있으면 원작 확인 문구와 다섯 번째 새 기술이 표시되는 Summary 화면을 사용하며, 원하는 기존 기술을 교체하거나 학습을 포기할 수 있습니다. 빈 칸에 배울 때도 원작 습득 메시지와 효과음을 표시합니다. 별도 교체 목록이나 기술 배열 직접 대입은 사용하지 않습니다.

창작 진화는 원본 EvolutionPhase의 시작·완료 문구, 울음소리, 애니메이션을 사용하고 미리보기·종족값·타입 적용만 어댑터로 연결합니다. 지어준 이름은 유지하며 별도 진화형 종명이 없으므로 원작 완료 문구의 진화형 이름 자리는 ‘새로운 모습’으로 표시합니다. 원작 포켓몬의 진화 이름과 동작은 그대로 유지합니다.
