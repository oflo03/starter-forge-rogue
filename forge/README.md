## 시작과 파트너

원본 타이틀의 **새 게임 → Starter Forge · 60웨이브**를 선택합니다. 심리테스트나 시드 입력은 없습니다. 매 모험마다 암호학적 난수로 맵 시드와 파트너 시드를 새로 만듭니다. 시드는 **메뉴 → 설정 → 일반**의 하단 메시지에서만 확인할 수 있습니다.

처음에는 무작위 단일 타입의 Lv.5 파트너 한 마리를 만납니다. 공개된 타입을 보고 이름을 직접 지어 주세요. 10·20웨이브 클리어 뒤에는 각각 Lv.10 파트너를 추가로 만나 같은 방식으로 이름을 정합니다. 창작 성장 파트너는 총 세 마리입니다. 포획·돈·도구·상점·교대·기술머신·일반 경험치·원작 포켓몬의 기술과 특성은 원본 시스템을 사용합니다. 원작 포획 편성은 유지하며, 편성이 가득 찬 상태에서 성장 파트너가 합류하면 작별할 일반 포켓몬을 직접 고릅니다.

파트너의 이미지는 임시로 원본 포켓몬 이미지를 사용합니다. 해당 이미지의 종과 파트너의 타입·종족값은 별개이며, 별도 창작 이미지는 아직 연결하지 않았습니다. 상대는 원본의 전 세대 출현 풀과 레벨·바이옴·트레이너 편성을 사용하고, 원작 기술·특성을 사용합니다.

초기 기술 세 개는 모두 원작 기술입니다. 시작 특성은 첫 타입 기술을 HP 1/3 이하에서 강화하는 심록 계열입니다. 풀·불꽃·물·벌레는 원작 심록·맹화·급류·벌레의알림을 그대로 사용하고, 나머지 타입은 같은 원본 효과 속성을 쓰는 확장 특성을 사용합니다. 지정 성장 보상 외의 경로로 창작 기술·특성을 자동 배정하지 않습니다.

## 성장

최종 종족값은 기존 메이커의 시드 생성식으로 결정하며 총합은 530입니다. 진화 단계별 기본 종족값 총합은 정확히 **310 → 420 → 530**입니다. 최종 값이 40 이하인 능력치는 모든 단계에서 그대로 유지합니다. 나머지는 비례 조정하되 HP·공격·방어·특공·특방·스피드 하한 **40·50·40·30·10·10**을 지키고, 정수화 후 차이는 조정 가능한 능력치에 배분합니다. 도구·융합·전투 중 보정은 원본 규칙으로 별도 적용합니다.

| 레벨 | 성장 선택 |
| --- | --- |
| 16 | 첫 진화, 창작 기술 하나 |
| 26 | 창작 특성 하나. 공격 강화 특성은 연계 공격기 두 개를 함께 제공 |
| 36 | 최종 진화, 두 번째 타입 선택 |
| 46 | 창작 기술 하나. 두 번째 타입 후보 포함 |
| 56 | 모든 개체값 +5 또는 하나를 V(31)로 조정 |

보상은 원본 아이템 선택 화면의 세 후보로 표시합니다. 추가 타입 17개는 세 그룹으로 나눠 그룹 안에서 최종 타입을 고릅니다. 기술 네 개가 찼으면 교체할 기술을 고릅니다. 특성으로 강화되는 공격기 둘을 유지하도록 교체 후보를 검사합니다. 원작 기술머신으로 이미 직접 바꾼 구성은 현재 개수보다 줄이지 않도록 검사하여 진행이 막히지 않게 합니다.

맵 시드는 성장 보상의 등급을 바꾸며, 파트너 시드·레벨·등급으로 후보를 고릅니다. 원작의 경험치와 도구를 사용하므로 합류 시점과 플레이에 따라 각 파트너가 성장 보상을 받는 웨이브는 달라집니다. 레벨 상한과 최종 웨이브는 60입니다.

| 웨이브 | 고정 전투 |
| --- | --- |
| 5 | 첫 라이벌 |
| 25 | 라이벌 |
| 40 | 악의 조직 보스 |
| 55 | 라이벌 |
| 60 | 최종 보스(원본 챔피언 편성) |

## 전투 구현과 저장

실제 진입점은 원본 `index.html` → `src/main.ts` → Phaser `BattleScene`입니다. 원본 PhaseManager·MoveEffectPhase·타입·급소·명중·상태이상·날씨·필드·도구·상점·AI를 사용합니다. 창작 데이터도 원본 `allMoves`·`allAbilities`에 등록하고 원본 효과 속성으로 처리합니다. 예전 별도 전투 엔진 `forge/game.ts`는 개발 기록으로 남았으며, 배포 게임에서는 실행하지 않습니다.

현재 창작 보상은 구현·검증한 공격 기술 계열과 특성만 노출합니다. 공격기·흡수·반동·선공·필중·급소·방어/특방 하락·풀죽음 계열, 힘자랑·브레인파워·겹겹코트·밸런스기어를 포함합니다. 기존 메이커의 모든 복합 전용기·창작 날씨·필드·특성을 포팅한 것은 아닙니다. 지원하지 않는 창작 효과는 보상에 나오지 않습니다. 원작 포켓몬·기술·특성은 원본 구현 범위를 그대로 사용합니다.

로그인 없이 원본의 로컬 저장 슬롯을 사용합니다. `CustomPokemonData.forge`에 시드·단계별 종족값·완료 보상을 보존합니다. 저장 복원 시 아직 선택하지 않은 성장 보상을 다시 확인합니다. 이전 간소화 엔진의 JSON 기록은 원본 슬롯 형식과 달라서 가져오지 않습니다.

## 개발·검증·배포

Node.js 24.9 이상과 pnpm이 필요합니다.

```sh
git submodule update --init --depth 1 assets locales
pnpm install --ignore-scripts
pnpm forge:dev
pnpm forge:typecheck
pnpm forge:test
pnpm forge:test:stats
pnpm forge:build
```

개발 주소는 http://127.0.0.1:5190 입니다. 빌드 결과는 루트 `dist/`이며, 원본 자산과 번역도 함께 복사합니다. Firebase의 `starter-forge-rogue-oflo` 사이트만 사용하므로 기존 스타팅 메이커 사이트는 변경하지 않습니다.

```sh
git archive --format=zip --output=dist/source.zip HEAD
firebase deploy --only hosting --project starter-forge-oflo
```

원본과 변경 소스는 루트 `LICENSE`의 AGPL-3.0을 따릅니다. 원본 이미지·음악·글꼴의 표기와 라이선스는 assets·locales 서브모듈을 참고하세요. 사용하지 않는 예전 모드의 별도 글꼴과 스프라이트 자료는 해당 폴더의 출처 표기를 유지합니다.
