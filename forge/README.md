# Starter Forge 원정대 · 초기 전투 버전

브라우저에서 세 마리의 창작 포켓몬을 기르는 60웨이브 로그라이크입니다.

- 플레이: https://starter-forge-rogue-oflo.web.app
- 소스: https://github.com/oflo03/starter-forge-rogue
- 배포본 소스 다운로드: https://starter-forge-rogue-oflo.web.app/source.zip
- 원작: https://github.com/pagefaultgames/pokerogue

## 진행

5문항 성향 테스트로 주인공의 단일 타입을 정합니다. 포켓몬 시드로 주인공과 동료 둘의 타입·최종 종족값·개체값이 정해집니다. 최종 종족값 합은 530이며, 기존 메이커의 순차 추첨식을 그대로 사용합니다. 같은 포켓몬 시드와 첫 타입이면 같은 팀이 만들어집니다. 맵 시드는 적과 전투 난수·보상 등급을 바꿉니다. 같은 개체·등급·성장 단계에서 보상 후보는 같습니다.

처음에는 Lv.5, 이후 웨이브에 따라 레벨이 오르며 Lv.60에서 끝납니다. 진화 전·첫 진화·최종 진화의 종족값 적용 비율은 60%·80%·100%입니다. 실능치는 중립 성격·노력치 0을 기준으로 계산합니다. 종족값은 관찰 문구로 조금씩 알려주고, 원정 종료 때 공개합니다. 브라우저 내 게임이므로 개발자 도구로 데이터를 보는 것을 막는 구조는 아닙니다.

| 레벨 | 세 마리 각각의 성장 선택 |
| --- | --- |
| 16 | 첫 진화 + 기술 하나 |
| 26 | 활성 특성 하나. 연계가 필요한 특성은 기술 둘도 함께 제공 |
| 36 | 최종 진화 + 추가 타입 하나. 17타입을 세 그룹의 카드에서 선택 |
| 46 | 기술 하나. 추가 타입 공격기를 최소 한 후보에 포함 |
| 56 | 개체값 여섯 개 +5 또는 원하는 하나를 V(31)로 조정 |

선택 화면은 세 장의 카드입니다. 기술이 네 개면 교체할 칸을 고릅니다. 특성으로 강화되는 기술 두 개를 유지하도록 교체를 제한합니다. 보상 등급에 후보가 부족하면 다른 등급에서 보충하고 카드에 표시합니다.

| 웨이브 | 상대 편성 |
| --- | --- |
| 5·25·55 | 라이벌, 2마리 |
| 40 | 악의 보스, 2마리 |
| 60 | 최종 보스, 3마리 |
| 나머지 | 야생, 1마리 |

일반 승리 후 생존 동료의 HP 35%와 모든 기술 PP 1을 회복합니다. 5웨이브마다, 그리고 특별 전투를 이긴 후에는 기절한 동료까지 모두 회복합니다. 전투 중 교대는 한 턴을 쓰고, 기절 후 교대와 웨이브 사이 교대는 무료입니다. 매 행동과 성장 선택을 로컬 저장소에 저장합니다. 시작 화면의 이어하기로 복구하고 JSON 기록을 내려받을 수 있습니다. JSON 가져오기 기능은 없습니다.

## 구현 범위

원본 PokéRogue 전체 소스를 보존하고, `src/data/type-chart.ts`의 순수 타입 상성표를 원작과 새 모드에서 공유합니다. 새 모드는 원본 Phaser 전투 장면을 실행하지 않으며, `forge/game.ts`의 별도 턴제 전투 엔진과 HTML 전투 화면을 사용합니다. 원작 이미지·사운드·번역 서브모듈을 내려받지 않아도 실행됩니다.

전투에는 물리·특수·혼합 타격, 타입 상성·자속, 스킨, 급소, 명중, 우선도·속도, 능력치 랭크, 연타, 흡수·반동, 회복·대타, 방어, 룸, 일부 지연 공격과 연계 특성을 구현했습니다. 메이커의 모든 콘텐츠를 실행하는 것은 아닙니다. 구현한 기술 템플릿·고유기·특성만 `TEMPLATES`·`FIXED`·`ABILITIES` 목록으로 보상에 노출합니다. 날씨·필드·설치물 전체, 상태이상 전투, 도구, 포획, 원작 전체 전투 시스템은 이 초기 버전에 포함하지 않습니다. 기술 설명에 회복 가능한 상태이상이 표시되더라도, 적이 그 상태이상을 부여하는 기능은 아직 없습니다.

스타팅 메이커 v1.10.0의 카탈로그와 생성기를 `vendor/`에 ESM 스냅샷으로 포함합니다. `MAKER_SOURCE.json`에 출처 파일 해시를 남깁니다. 원본 메이커와 이 게임은 별도로 배포됩니다.

## 이미지

전투 필드·체력바·기술·교대 화면은 표시하고, 창작 포켓몬 이미지 두 자리만 비워둡니다. 이미지나 대체 캐릭터는 생성하지 않았습니다. 이후 이미지가 준비되면 `ui.ts`의 `battlefield()`에서 `.own-portrait`와 `.enemy-portrait` 안을 이미지로 바꾸면 됩니다. 현재 저장 데이터의 `image`는 비어 있습니다.

## 실행과 검증

루트에서 Node.js 24 및 pnpm으로 실행합니다.

```sh
pnpm install --ignore-scripts
pnpm forge:dev
pnpm forge:typecheck
pnpm forge:test
pnpm forge:build
```

개발 주소는 http://127.0.0.1:5187 입니다. 배포 폴더는 `forge/dist`입니다. 원작은 기존 루트 명령과 서브모듈 준비 절차를 따릅니다.

17개 자동 검사로 시드 재현·상성·성장 15회·특별 웨이브·IV·기술 배정·피해·연계·저장 등을 확인했습니다. 브라우저에서 성향 테스트, 공격, 저장 복원, 다섯 단계의 세 마리 성장 선택 및 기술 교체를 확인했습니다. 모바일 폭 390px에서도 가로 넘침 없이 선택할 수 있습니다. 난이도는 초기 조정 상태이며 장기 플레이 밸런스 검증은 남아 있습니다.

## 라이선스와 배포

원본과 변경 소스는 루트 `LICENSE`의 AGPL-3.0을 따릅니다. 원본 저작권 표기를 유지합니다. 로컬 IBM Plex Sans 글꼴은 `public/fonts/OFL.txt`를 따릅니다.

Firebase 프로젝트 `starter-forge-oflo`의 별도 Hosting 사이트 `starter-forge-rogue-oflo`로 배포합니다. 기존 메이커 사이트를 덮어쓰지 않습니다. 소스 아카이브는 커밋 후 다음 순서로 생성·배포합니다.

```sh
pnpm forge:build
git archive --format=zip --output=forge/dist/source.zip HEAD
firebase deploy --only hosting --project starter-forge-oflo
```
