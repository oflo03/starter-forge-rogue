# UI 검증

true-black-flat 방향을 적용했습니다. 기존 Starter Forge의 IBM Plex Sans(로컬 Forge Sans 별칭)를 유지하므로 direction의 keep type을 지정했습니다. 한국어는 시스템 글꼴로 보완합니다. 이미지는 사용자 요청에 따라 창작 포켓몬 자리만 비웠습니다.

실제 Chrome의 1440px·390px 화면에서 전투 배치와 성장 카드 스크린샷을 검토했습니다. 모바일 카드 대화상자는 내부 스크롤을 사용합니다. 인터랙션 검사에서 다섯 성장 단계 × 세 마리, 기술 교체, 저장 복원과 공격 클릭을 통과했습니다. 인트로의 큰 제목은 시작 화면 용도로 유지하며 실제 전투 화면에는 작은 웨이브 제목을 씁니다. 린트 0 FAIL. 보상 카드의 숫자는 선택 순서, 웨이브 숫자는 진행 상태입니다.
